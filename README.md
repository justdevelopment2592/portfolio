# Portfolio

A responsive welcome page for Justin Familaran's software development portfolio.

## Run locally

Open `portfolio.code-workspace` in VS Code, then open `index.html` in a browser.
For automatic refresh while editing, use any local static server such as VS Code's
Live Server extension.

## Deploy

This is a buildless static site. Import the repository into Vercel and keep the
framework preset set to **Other**; no build command or output directory is needed.
